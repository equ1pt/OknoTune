OknoTune — настройка Windows 10/11 с откатом

Запуск: двойной клик по OknoTune.cmd и согласие на права администратора.
Если Windows покажет SmartScreen: «Подробнее» → «Выполнить в любом случае».

Быстрый путь (2 минуты):
1. На главной выберите профиль: «Рекомендуемое», «Для игр» или «Максимум приватности».
2. Ответьте «Да/Нет» на простые вопросы (ноутбук и SSD определяются сами).
3. Проверьте окно «Что изменится» — там же предупреждения — и нажмите «Применить».

Для любопытных: «Свой выбор» или разделы слева — полный список с описаниями.
Цветная полоска на карточке: зелёная — безопасно, жёлтая — по ситуации, красная — удаление.

Откат: раздел «История» — любое применение можно откатить отдельно.
Удалённые приложения так не вернуть, их ставят заново из Microsoft Store.
Перед применением можно создать точку восстановления (переключатель в окне подтверждения).
Снимки старше полугода удаляются сами; кнопку «Очистить историю» стирает их все.

Инструменты (слева внизу):
  Очистка диска — временные файлы, кэши обновлений, миниатюр, шейдеров, браузеров, корзина.
                  Показывает размер до удаления. Документы и загрузки не трогает. Удалённое не вернуть.
  Автозагрузка  — программы, запускающиеся при входе в Windows. Отключение обратимо: запись
                  сохраняется у OknoTune и возвращается одним нажатием (или через «Историю»).
                  Видны и записи, отключённые в Диспетчере задач, — их можно вернуть.
  Драйверы      — видеокарта, материнская плата/ноутбук, чипсет, сеть, звук и сломанные устройства.
                  Показывает возраст драйвера и открывает страницу производителя в браузере.

Снимки и журнал лежат в %LOCALAPPDATA%\OknoTune.
Скрипт ничего не скачивает и никуда не отправляет. Весь код в OknoTune.ps1.

Используйте на свой риск: программа меняет настройки системы. Перед применением
включайте точку восстановления. Автор не отвечает за последствия (см. LICENSE).

Для разработчика:
  OknoTune.ps1 собирается из файлов в parts/ склеиванием по порядку имён.
  Правьте parts/*.ps1, затем:  powershell -ExecutionPolicy Bypass -File build.ps1
  Проверки: OknoTune.ps1 -Selftest (состояние без изменений, без окна),
            OknoTune.ps1 -Snapshot a.png -View home|wizard|review|list|history|clean|startup|drivers
            (отрисовать экран в PNG и выйти — без изменений в системе).
